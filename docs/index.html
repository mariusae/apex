apex

apex is a modernised acme: text first, mouse oriented, plumbing everywhere, fast and simple. It keeps acme's way of working, and adds what acme lacks for today's work: a client and a server, so the window can go and come back, here or over ssh; terminals in its windows, for running programs and coding agents; and an interface for programs that does not need a mounted file system.

The acme experience

  • Three buttons and their chords. B1 selects, B2 runs what it touches, B3 looks for it or opens it.
  • Columns and windows tiled as acme tiles them, each with a tag: text you type commands into and run.
  • Everything is text. A command's output is text in a window, to be edited, run or plumbed in its turn.
  • Plumbing: rules that say what a word means where it is clicked, and which program takes it.

Sessions

Everything a workspace holds (its columns, windows, terminals and what runs in them) lives in a session on a daemon. The app is a view of it. Close the window and the session goes on; attach again and it is all there. A daemon holds many sessions, and the app shows them as tabs.

apex attach                  # the app, on this machine's session
apex attach devbox/work      # a session on another machine, over ssh

On another machine nothing is copied: the files stay where they are, and apex puts its own small daemon there to edit them.

Terminals and agents

A terminal is a window like any other. A program running in one (a shell, a build, a coding agent) drives the editor with the apex command, as a script would: opening files, writing to windows, asking for the user's attention.

Scripting

The apex command does everything the mouse does. A workspace is a script:

s=$(apex new-session work ~/src/apex)
apex -session $s open README.md
apex -session $s term new make watch

Programs can also attach to a session themselves, through libraries for Rust and Go or a bridge that speaks JSON, and offer rules, own windows and answer what is clicked in them.

Building

apex is written in Rust. The app is for the Mac; the daemon and the apex command also run on Linux, where the app attaches to them over ssh.

git clone https://github.com/mariusae/apex
cd apex
mac/build-app.sh             # target/Apex.app
